# claude-remote

Удалённый веб-терминал для Claude Code на личном Windows 11 ноутбуке. С телефона (через браузер) вы видите живой терминал, в котором работает `claude`, пишете в него, одобряете запросы, прерываете (Ctrl+C) и по кнопке «Экран» получаете скриншот экрана ноутбука.

Один Go-бинарник, без базы данных и без пользователей: токен один, пользователь один.

> **Внимание.** Эта программа даёт полный шелл на вашем ноутбуке. Любая дыра означает полный захват машины. Читайте раздел «Модель угроз».

```
Телефон (браузер, xterm.js) ──Tailscale──► сервер на ноуте
   WebSocket: ввод/вывод/resize   ◄──►  ConPTY  ◄──►  claude (или powershell)
   HTTP GET /screenshot           ◄──     захват экрана → PNG
```

## Установка Tailscale

1. Установите Tailscale на ноутбук и на телефон: <https://tailscale.com/download>.
2. Войдите в **один и тот же** аккаунт на обоих устройствах.
3. **Включите 2FA** у провайдера входа (Google, Microsoft, GitHub и т. д.). Кто получит доступ к вашему аккаунту Tailscale, тот окажется в вашей сети.
4. Убедитесь, что у ноутбука есть адрес вида `100.x.y.z` (`tailscale ip -4`).
5. Включите на ноутбуке автозапуск Tailscale (по умолчанию включён).
6. По желанию в консоли администратора Tailscale включите *Device approval* и настройте ACL так, чтобы к ноутбуку по порту 8443 могли обращаться только ваши устройства.

## Отключение сна ноутбука

Пока ноутбук спит, сервер недоступен:

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

Для работы от батареи используйте `-dc` вместо `-ac`. Крышку лучше не закрывать (или задайте в настройках питания «Ничего не делать» при закрытии крышки).

## Сборка

Нужен Go (версия указана в `go.mod`).

```powershell
go build -o claude-remote.exe ./cmd/claude-remote
```

## Первый запуск и токен

```powershell
.\claude-remote.exe --workdir C:\Users\you\projects\my-project
```

- Сервер сам находит адрес Tailscale (`100.64.0.0/10`) на сетевом интерфейсе с именем `Tailscale` и слушает только на нём, порт **8443** (диапазон 100.64/10 используют и мобильные операторы, поэтому одного адреса недостаточно). Если Tailscale не найден, сервер завершается с ошибкой и **не** слушает `0.0.0.0`.
- При первом запуске в консоли **один раз** печатается токен. Скопируйте его в менеджер паролей. Токен хранится в `%APPDATA%\claude-remote\config.json` (доступ только вашему пользователю) и больше нигде не показывается и не пишется в логи.
- Новый токен (например, после утечки): `.\claude-remote.exe token rotate`, затем перезапустите сервер. После перезапуска все старые сессии браузера перестанут работать.

### Флаги

| Флаг | Назначение |
|---|---|
| `--workdir DIR` | рабочая папка процесса (по умолчанию текущая) |
| `--cmd CMD` | что запускать (по умолчанию `claude`; можно `powershell`) |
| `--listen IP:PORT` | переопределить адрес. `127.0.0.1:PORT` разрешён для тестов; `0.0.0.0` и `::` отклоняются |
| `--i-know-this-is-dangerous` | разрешить `0.0.0.0` / `::`. **Не используйте** |
| `--tls-cert`, `--tls-key` | включить HTTPS (см. ниже) |
| `--allow-host NAME` | дополнительное имя в заголовке `Host` (например, имя MagicDNS), если заходите не по IP |
| `--config-dir DIR` | другая папка конфига (для тестов) |

`--cmd` и `--workdir` задаются только при запуске; клиент не может выбрать, что запускать.

Процесс запускается лениво, при первом подключении клиента (чтобы не держать `claude` без нужды), и дальше живёт независимо от того, подключён ли кто-то. После завершения процесса он **не** перезапускается сам: нажмите «Перезапустить».

### HTTP и HTTPS

По умолчанию используется обычный **HTTP поверх Tailscale**. Трафик уже шифруется WireGuard между вашими устройствами, но браузер считает страницу небезопасной: на телефоне могут не работать буфер обмена и часть PWA-функций, а cookie не получает флаг `Secure`.

Для HTTPS используйте сертификат Tailscale (включите HTTPS и MagicDNS в консоли администратора):

```powershell
tailscale cert my-laptop.tailnet-name.ts.net
.\claude-remote.exe --tls-cert my-laptop.tailnet-name.ts.net.crt --tls-key my-laptop.tailnet-name.ts.net.key --allow-host my-laptop.tailnet-name.ts.net
```

Затем заходите на `https://my-laptop.tailnet-name.ts.net:8443`. Собственный CA не используется.

## Автозапуск (Task Scheduler)

Запуск при входе пользователя, с задержкой 30 секунд, чтобы поднялся Tailscale. Подставьте свои пути; `/IT` нужен, чтобы процесс работал в вашей интерактивной сессии (иначе скриншоты не получатся):

```powershell
schtasks /Create /TN "claude-remote" /SC ONLOGON /DELAY 0000:30 /RU "$env:USERNAME" /IT /RL LIMITED /F `
  /TR "\"C:\tools\claude-remote\claude-remote.exe\" --workdir \"C:\Users\you\projects\my-project\""
```

Удалить: `schtasks /Delete /TN "claude-remote" /F`. Остановить сейчас: `schtasks /End /TN "claude-remote"`.

Если Tailscale не успел подняться, сервер завершится с ошибкой; запустите задачу вручную (`schtasks /Run /TN "claude-remote"`) или увеличьте задержку.

## Использование с телефона

1. Откройте `http://100.x.y.z:8443` (или HTTPS-имя). Введите токен: сервер поставит cookie `HttpOnly; SameSite=Strict` со случайным идентификатором сессии (сам токен в cookie не кладётся). Токен нигде не сохраняется в браузере.
2. Работайте в терминале. Нижняя панель: Esc, Tab, Ctrl (залипающая: нажмите Ctrl, затем букву), ^C, ^D, стрелки, Enter, `|`, `/`, `~`.
3. **Экран**: открывает скриншот (по умолчанию уменьшен до ширины ~1280). «Обновить», «авто (5 с)». Тап по картинке закрывает.
4. **Перезапустить**: завершает процесс вместе со всеми дочерними и запускает заново (с подтверждением).
5. Индикатор показывает состояние соединения; при обрыве клиент переподключается с нарастающей задержкой. При переподключении терминал очищается и приходит свежий буфер (последние ~256 КБ вывода).
6. Добавьте страницу на домашний экран (PWA).

Одновременно можно подключить несколько клиентов (телефон и браузер на ноутбуке). Ввод принимается от всех, вывод получают все, размер терминала берётся от последнего приславшего resize.

## Модель угроз

**Что защищено**

- Порт слушает только Tailscale-адрес: он недоступен из интернета и из обычной локальной сети. Без Tailscale сервер не стартует.
- Любой запрос (страница, WebSocket, скриншот) требует токен: 32 байта из `crypto/rand`, сравнение в постоянное время (`subtle.ConstantTimeCompare`). Токен принимается только из cookie или заголовка `Authorization: Bearer`, **не** из строки запроса.
- Перебор токена: не более 5 неудачных попыток на IP за 5 минут, затем блокировка 1, 2, 4 … минут (до часа). Состояние в памяти.
- Защита от cross-site WebSocket hijacking и CSRF: обязательный `Origin`, равный `Host`; cookie `SameSite=Strict`. Защита от DNS-rebinding: `Host` должен быть IP-адресом или именем из `--allow-host`.
- Заголовки: CSP (`default-src 'self'`, без inline-скриптов), `nosniff`, `no-referrer`, `X-Frame-Options: DENY`.
- Клиент не может задать команду, папку или путь; файловых операций нет. Размер входящего WebSocket-кадра ограничен (256 КБ).
- В логах нет токена, cookie и содержимого терминала (проверяется тестом).
- Файл конфига доступен только вашему пользователю (ACL без наследования, проверяется при каждом чтении).
- При завершении сервера (и при его принудительном убийстве) всё дерево процессов убивается через Job Object.

**Что НЕ защищено**

- Любой, у кого есть токен **и** доступ к вашей tailnet, получает полный шелл от вашего имени. Защитите аккаунт Tailscale (2FA) и токен (менеджер паролей).
- Любой процесс на ноутбуке под вашим пользователем может прочитать `config.json`, а любой, кто может сидеть за ноутбуком под вашей учётной записью, и так имеет всё.
- По HTTP без TLS cookie с токеном передаётся внутри туннеля WireGuard, но не защищена на уровне браузера. Другие устройства вашей tailnet могут пытаться подключаться (ограничьте их ACL в Tailscale).
- Скриншот показывает весь экран, включая уведомления и пароли, если они на экране.
- Сессия живёт 30 дней в памяти сервера и не привязана к устройству. Отозвать все сессии: перезапустить сервер (после `token rotate` это и так нужно).

**Что делать при утечке токена**

1. `.\claude-remote.exe token rotate` (печатает новый токен).
2. Перезапустите сервер (`schtasks /End` и `/Run`).
3. Если подозреваете доступ к ноутбуку: удалите чужие устройства из Tailscale, смените пароль аккаунта, проверьте, что делал `claude` в истории терминала.

## Известные ограничения

- **Блокировка экрана**: на заблокированном экране скриншот чёрный или показывает экран входа (захват через GDI). Терминал при этом работает.
- Скриншот не показывает окна с защитой от захвата.
- Сессия **не переживает перезагрузку** ноутбука и завершение сервера: запускается новая.
- Буфер вывода 256 КБ: при подключении содержимое восстанавливается с ближайшей границы строки; цвета и режимы, заданные в отброшенной части, могут не восстановиться до следующей перерисовки программой.
- Дочерний процесс помещается в Job Object сразу после запуска; теоретически потомок, созданный в первые микросекунды, мог бы не попасть в него.
- Работа с реального телефона через Tailscale в разработке не проверялась автоматически: см. чек-лист в отчёте.

## Разработка

```powershell
gofmt -l .          # должен быть пустым
go vet ./...
go test ./...
govulncheck ./...   # go install golang.org/x/vuln/cmd/govulncheck@latest
```

Код, зависящий от ОС, разнесён на `*_windows.go` / `*_other.go`, поэтому `go vet` проходит и на Linux. Интеграционные тесты ConPTY запускаются только на Windows.

Версии и контрольные суммы xterm.js: `web/vendor/VERSIONS.md`.
